2 主流程

① 打开从文件列表、云盘、系统分享、「打开方式」或文档链接点一下，直接进编辑窗口。没有导入，没有转换。打开不会改动文件。
② 自动空间化应用按规则把内容排好：表格里的图表在旁边变成 3D；点 [铺开] 进全空间，章节 / 列 / 页沿圆弧排在身边。不用自己摆。
③ 编辑键鼠打字、改表、排页。改的就是这个文件的内容。
④ 保存Ctrl+S 写回同一个文件、同一种格式。空间摆法另外记着，不进文件。[另存为] 是换格式或换地方。

3 不自造格式：内容和呈现分开

内容呈现
是什么文件本身：文字、单元格、公式、页、图表数据这些内容在空间里怎么摆：哪一块在哪、弯不弯、图表是不是 3D、钉了哪些卡
格式标准格式：.docx / .xlsx / .pptx / .html / .pdf，飞书云文档应用自己的一份「布局记录」，很小，纯摆位信息
存在哪原来的位置（本机、云盘、飞书）这台头显的应用数据里；或者文件旁边的 .spatial.json
没有它会怎样—没有布局记录时，应用按第 3.2 节的规则自动排。别的软件完全不受影响

3.1 怎么读写标准文件：只改动过的地方

  • 打开：读文件，画出来。打开这一步不写文件。
  • 保存：.docx / .xlsx / .pptx 本身是一个压缩包，里面是很多个部件。保存时只改写你动过的那些部件里对应的那几处，别的部件原封不动地放回去。这里看不懂的内容（智能图形、修订、条件格式、动画、宏……）应用不解析、不重写，所以它们在文件里不会变。
  • 显示近似不等于改文件：头显上没有完整的办公排版引擎，有些版式这里画不出原样（比如双栏按单栏显示）。这只是显示上的差别，文件里的版式属性没有动，电脑上打开还是原来的样子。
  • 不许悄悄丢：文件里的每一项内容，要么能改，要么只读显示，要么不显示但原样保留。三种情况都列在「兼容性」清单里（第 4 节）。
  • 保存要安全：先写临时文件，校验能重新读出来，再替换原文件。没保存的改动每 3 秒记进应用数据里的恢复记录，崩溃和断电后能找回。

3.4 文件在别处被改过怎么办

  • 再打开时先比指纹。没变，原样还原摆法。
  • 变了（在电脑上加了一章、删了一列）：锚点还对得上的块回到原来的位置，对不上的块按自动规则补在后面，不报错、不弹框。
  • 文件改了名字或挪了位置：本机文件靠内容指纹找回；找不回就当新文件，自动排。

3.5 格式与商标合规

结论：直接新建、打开、保存 .docx / .xlsx / .pptx 是可以的；不能用的是别家的产品名和图标。下面是依据和落到产品上的规矩。这一节是产品规矩，不是法律意见，对外发布前请法务按这里的清单确认一次（第 14 节）。

问题依据
这三种格式是谁的.docx / .xlsx / .pptx 的正式名字是 Office Open XML（OOXML）。它是公开的国际标准：Ecma 的 ECMA-376，和 ISO / IEC 的 ISO/IEC 29500。标准文本公开，任何人都可以按它实现读写
按标准实现会不会侵犯专利微软对这份标准有公开的「开放规范承诺」（Open Specification Promise）：对任何人实现这份规范所必需的专利，不可撤销地承诺不主张权利，不用签协议、不用付费
别人是不是也这么做是。WPS、LibreOffice、Google 文档等都直接新建和保存这三种格式
那什么不能用商标和图标：Word、Excel、PowerPoint 这些产品名，以及对应的图标（带 W / X / P 字母的色块）。还有别家软件自带的字体、模板和素材，这些各有各的授权，不随格式开放

落到产品上的规矩（应用内文案、图标、商店页、宣传素材都算）：

可以不可以
说兼容性「兼容 .docx / .xlsx / .pptx」「直接打开和保存 .docx」。只用扩展名，或标准的名字用别家的产品名来称呼文件或功能，比如「某某文档」「某某表格」；用别家办公套件的名字指代这类文件。统一说「文档 / 表格 / 演示」「办公文件」
文件图标自己画的：文档是几行横线，表格是网格，演示是一页带图形的版面（样稿用的就是这套）。蓝 / 绿 / 橙只是区分三类的通用颜色别家的图标，或模仿它的样子（字母色块、同样的造型）
界面SpatialUI 组件的样子照抄别家办公软件的界面布局和工具条造型
字体文件里指定的字体头显上没有时，用系统字体或开源字体代替，并在兼容性清单里列出「字体已替换」；保存时不改文件里写的字体名把别家软件自带的字体打进安装包
模板和素材v1 只有空白文件；以后的模板自己做搬别家的模板、剪贴画、主题
文件里的署名新建和保存的文件里，「由哪个程序创建 / 修改」写本应用自己的名字写成别家软件的名字
云服务的名字飞书、Google Drive、OneDrive、Dropbox：只在「连接哪个服务」的地方用文字写出名字，用通用的云图标。要放对方的图标，等登记应用时按对方的品牌规范来让人以为本应用是对方出的，或得到了对方的认可
声明设置页底部一句：「提到的文件格式和云服务名称，只用来说明兼容和连接。本应用和这些名称的权利人没有隶属或背书关系。」商店页同样放一句—
宣传素材按工厂规矩不出现任何公司名，只写「兼容 .docx / .xlsx / .pptx」—

样稿已经按这套规矩检查过：中英文文案里没有别家办公软件的产品名，文件图标都是自己画的，没有字母色块。两处我没有把握、已列进第 14 节的：

  • 英文名 Spatial Office 里有 Office 这个词。它是通用词，但在办公软件这一类里别家有相关商标，对外发布前建议做一次商标检索；中文名「空间办公」没有这个问题。

6.2 空间排布

  • 数量上限：同时最多 9 块活的面板加 1 个图表。更多的块收在圆弧两端，转过来时再换入。

6.3 曲面（curved）

平台现状：PICO CLI 自带的 SpatialUI 组件、设计 skill 和 SDK 参考里都没有曲面面板，也没有「把界面贴到弯曲网格上」的能力。有的是：全空间里可以任意摆放和朝向的平面附着面板。这条已经记进给 CLI 团队的反馈。

v1 做法：分段折面。把内容切成几块平面板，沿圆柱排，每块正对座位。

  • 每段不超过 0.6 m 宽。半径 1.4 m 时一段约 25°，段中点偏离理想圆柱约 3 cm，离眼睛的距离只差 2%，看不出来。
  • 接缝放在内容本来就有分界的地方：表格的列线、文档的页边、幻灯片之间。所以宽表、长文、故事线都不会被缝切开。
  • 一整幅连续的画面（比如预演的大屏）不做曲面，保持平的，避免折角。
  • 布局记录里只写 curved: true 和半径。以后平台有真曲面，换实现就行。

6.4 空间图表

  • 文件里是标准图表，这里按 3D 呈现。工作簿里已有的柱形图、散点图，打开时自动在旁边变成 3D。别的软件打开同一个文件，看到的还是普通的 2D 图表。
  • 在表格里选一块数据，点 [3D 图表]：在文件里新建一个标准图表（簇状柱形图，或散点图），同时按 3D 呈现。v1 3D 柱状图、3D 散点图（第三个维度在文件里写成气泡大小）；v1.x 3D 面图。
  • 联动是双向的：改单元格，柱高在半秒内跟着变；点一根柱子，表格里选中对应单元格并显示数值；在表格里选中数据区的单元格，对应柱子高亮。
  • 拖动绕竖轴转着看；[复位视角]。视角和 3D 样式记在布局记录里。
  • 文档和演示里的图表：读文件里图表自带的数据来画。窗口里显示 2D，铺开时是桌面上的 3D，预演时从屏幕里出来。[放进演示] 把表格里的图表复制成演示里的一个标准图表。
  • 配色：四个系列固定顺序，已经过色盲区分和对比度校验；图例始终在，点选能读到具体数值。

6.5 演示：故事线和空间预演

  • 故事线：所有页沿圆弧排开，按节分段。拖一页就是调顺序，拖过缺口就是换节。这两种改动写回 .pptx（页的顺序和节本来就是文件内容）。
  • 预演：正前方 3.4 m 处一块 3.2 m 宽的大屏；讲者备注在左手边 58°、1 m；计时和下一页在右手边；页里的图表出屏，变成屏幕前的 3D 实体。键盘 → ← 或空格翻页，Esc 结束。这三块的位置记在布局记录里。

6.6 只有空间里才成立的两点

  • 钉卡：把正文里的一个块（表格、图、一段话）拎出来钉在身边固定的位置。翻到哪一章它都在，适合边看数据边写结论。内容还是正文里那一份，改一处两处都变。「钉在哪」记在布局记录里。
  • 转到面前：见 6.2。坐着办公时，转的是内容，不是脖子。

9 账号与云盘（可选）

9.1 规矩

  • 可选。一个都不连接时，本机文件的打开、编辑、铺开、保存、另存为全部可用，全程离线。
  • 只走对方的官方授权。应用不出现密码输入框，拿不到密码。
  • 登录凭证加密存在这台设备上，只有这个应用能读；到期前自动续期；退出登录就删除。
  • 云盘是文件来源，不是另一套功能：和本机文件一样浏览、打开、保存回原处、进「最近」。

10 浏览器和电脑

10.1 浏览器 → 应用

  • 下载的文件：应用登记自己能打开的类型（.docx、.xlsx、.pptx、.html、.pdf、.png、.jpg、.md、.csv）。这些都是系统本来就认识的标准类型，不需要登记任何自定义类型。在头显浏览器里下载完，点开或选「打开方式」就直接打开。
  • 分享：应用是系统分享的目标。浏览器里把文件或链接「分享」给空间办公。
  • 云文档链接：应用登记飞书和 Google 文档页面的网址样式（只有文档、表格、幻灯片的网址，不含其他网页）。在浏览器里点到或分享这类链接时，出现「在空间办公中打开」；应用认出是哪一篇，连接后直接打开。
  • 说明：这两个网站不是我们的，系统不会把这类链接默认交给我们，是否出现在「打开方式」里取决于头显浏览器怎么处理（第 14 节要验证）。所以「分享」是保底的路，一定能用。
  • 应用还登记一种自己的链接 spatialoffice://open?url=…，给电脑上的脚本和 adb 用。
  • .html 默认还是浏览器打开。空间办公只出现在「打开方式」里，不抢默认；也不接管普通网页链接。

10.2 应用 → 浏览器

  • 飞书和 Google 的云文档：更多菜单里 [在浏览器中打开原文档]，交给头显浏览器打开网页版。
  • 本机的 .html：更多菜单里 [用浏览器打开]。

上一版的「网页版查看器」删掉了：没有自有格式之后，文件本身就是标准的，电脑和手机上用原来的软件或浏览器就能打开，不需要我们再做一个查看器。

11 输入和默认规矩

  • 键鼠是主输入。常用操作都有快捷键，设置里有快捷键表。Ctrl+S 保存，Ctrl+E 另存为，Ctrl+Shift+空格 铺开 / 收起，Ctrl+Alt+← / → 转到面前，Ctrl+Alt+1 / 2 / 3 切排布，F5 / Esc 预演。
  • 手柄射线、手势射线、眼手三种都能点到所有按钮、列表、单元格、缩略图、柱子；打字走系统输入法。
  • 中英双语，设置里即时切换；用户文件的内容不翻译。
  • 设置里有「退出应用」，带确认。
  • 共享空间里不承诺窗口「回到面前」；全空间里的摆位由应用负责。
  • 本机文件的全部功能离线可用，不需要账号。账号只用于云端，是可选的；核心功能不依赖私钥或付费接口。
  • 界面上的名字、图标都是原创；宣传材料里不出现公司名，兼容性只用扩展名表述（细则在第 3.5 节）。

14 风险和先做的验证

要验证的为什么担心不行的话
「只改动过的地方」的保存这是这一版里最难的一块。要在保留看不懂的内容的同时改它旁边的内容，写得不对，电脑上打开会提示「需要修复」。表格里插入和删除行列时，还要把图表、条件格式、数据验证、名称里引用的区域跟着移某一类内容保不住时，含这类内容的文件降成只读，只能另存为副本，并在兼容性清单里说明。困难组的 N3 就是用来尽早发现这种情况的
格式与商标合规的法务确认第 3.5 节的依据来自公开资料（标准文本和公开的专利承诺），没有经过法务确认；各个上架地区的要求可能不一样对外发布前请法务按第 3.5 节的清单确认一次。在那之前只给内部和测试用户用
英文名里的 Office 一词通用词，但在办公软件这一类里别家有相关商标；没有做过商标检索检索有风险就换英文名，中文名「空间办公」不变。文件夹名 Documents/SpatialOffice 和链接前缀 spatialoffice:// 跟着一起换，所以要在第一次对外发布前定
